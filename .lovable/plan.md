# Cute Romantic Apology Letter

## Experience
- Replace the current three-step floral card with a focused two-part story: a full-screen teddy-bear apology cover, then the handwritten letter.
- Make the cover immediately say “I’m Sorry, My Baby 🥺❤️,” with a custom teddy illustration, flowers, hearts, sparkles, and a clear “Open My Letter 💌” action.
- Transition smoothly into a warm paper letter containing the specific apology: not making enough time, missing the effort she made getting ready, understanding why she felt ignored, and promising to do better.

## Interaction
- Add gentle floating hearts and sparkles that stay behind readable content.
- Add an optional music control that starts only when tapped, using a quiet built-in instrumental melody so no external audio file is required.
- End with “Forgive Me? 🥺” and two affectionate choices. Either choice triggers a celebratory heart/confetti moment and “Thank you, my love! ❤️🧸”.
- Include a discreet way to return to the cover after opening the letter.

## Visual Direction
- Use a custom soft illustrated teddy scene as the main visual, supported by blush, berry, cream, and warm green accents.
- Use romantic display and handwriting styles, soft shadows, rounded individual elements, and restrained animation.
- Keep every screen polished and readable on both phones and desktops, including reduced-motion behavior and accessible controls.

## Technical Details
- Keep the implementation frontend-only in the existing app, with no database or backend.
- Use React state for page transitions and celebration state, CSS for ambient motion, and the browser audio API for opt-in music.
- Preserve route-specific title, description, Open Graph, and Twitter metadata.
